# 🎓 University Transfer Platform — e-Transfert

**A web platform for managing internal and external university transfer applications.**

e-Transfert is a university project developed to digitize and simplify the management of student transfer applications. It enables students to submit applications online, upload supporting documents, and track their application status, while providing university administrators with tools to review and process requests efficiently.

## 📌 Project Overview

University transfer procedures can be complex, time-consuming, and difficult to track manually. This project aims to provide a centralized digital solution that improves transparency, reduces administrative workload, and makes the transfer process easier for students and university staff.

Developed as part of a Bachelor's degree final-year project at **Université M’hamed Bougara de Boumerdès (UMBB), Algeria**.

## ✨ Features

### 👨‍🎓 Student Space
- Secure user registration and authentication.
- Submit internal and external transfer applications.
- Upload required supporting documents.
- Track application status.
- Receive notifications when application status changes.
- Access personal application information.

### 🏛️ Administration Space
- View and manage transfer applications.
- Review student information and submitted documents.
- Accept or reject applications.
- Request additional documents or corrections.
- Track application processing.
- Access dashboards and statistical information.

### ⚙️ General Features
- Centralized transfer application management.
- Role-based access for students and administrative staff.
- Improved traceability of application processing.
- Multilingual interface supporting three languages.
- Designed to simplify university administrative procedures.

## 👥 User Roles

| Role | Responsibilities |
|---|---|
| Student | Submit applications and track their progress. |
| Administration (VRP) | Review and manage submitted applications. |
| Vice-Dean | Review applications and make final decisions. |

## 🔄 Application Workflow

1. The student signs in to the platform.
2. The student selects the type of transfer.
3. The student completes the application form.
4. Required supporting documents are uploaded.
5. The application is submitted for review.
6. The administration examines the application and may request corrections.
7. The authorized academic official makes the final decision.
8. The student checks the application status and receives updates.
